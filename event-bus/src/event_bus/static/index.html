Approval Gates
Idea Approval
Always ON — ideas require human approval before the planner runs.
Plan Approval
Hold the plan after decomposition — review the epics/stories on the board and start it, so a large plan doesn't run automatically.
PR Merge Approval
Hold merged PRs for manual approval via the Approve PR form.
Security Sign-off Required
Block PR merge if the security scan returns a failing verdict.
Free Models Only
Advisory flag — restrict all roles to free OpenRouter models or local Ollama. Use the panel below to browse and apply free models.
Auto-escalate on stall
When a story exhausts its recode attempts, escalate the coder and reviewer to a stronger model for one more round before flagging it for you. Breaks free-model deadlocks automatically; only the truly-hard ones reach the attention tray.
Free & Local Models

Pre-loads the free model cache (2 h TTL). Then use the Free ▾ button next to each role to browse and assign individually.
